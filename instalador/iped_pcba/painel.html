IPED-PCBA

O painel conduz o trabalho do começo ao fim: preparar a máquina, processar a evidência, analisar com gráficos e IA, e fechar o relatório técnico.

1. Configurar a máquina

  
O painel lê o hardware e propõe a configuração do IPED. Você pode desmarcar ou editar cada item antes de aplicar. Tudo tem backup.

  

    
IPED desatualizado

    
Depois, aplique de novo a configuração abaixo para levar os ajustes da PCBA ao IPED novo.

  

  

    
Atualizações do IPED-PCBA

    
O painel confere no GitHub, ao abrir, se saiu uma versão nova. Só lê a lista de versões: nada da máquina ou dos casos é enviado. A versão em uso fica guardada como cópia ao lado (iped-pcba-anterior-versão), para voltar se precisar.

    
Verificando…

    
  

  

    
IPED não encontrado

    

      
      

    
Não tem o IPED? O painel baixa a versão oficial do GitHub do IPED, confere o SHA-256 e instala sozinho (uns 700 MB).

verificando…

No Assistente de IA do painel as skills já aparecem numa lista própria, sem instalar nada. Para o Claude Code e o Hermes, o botão abaixo copia as skills para a pasta que cada um lê sozinho.

    

    

    
2. Claude Desktop e claude.ai: envio manual, uma vez por skill

    
O Claude Desktop guarda as skills na sua conta Claude, não numa pasta do computador, por isso o painel não consegue instalar sozinho. Ele gera um .zip por skill e você envia cada um:

    
    
      
  1. Abra o Claude Desktop e vá em Personalizar > Skills (em algumas versões: Configurações > Capacidades > Skills).
    2. 
      
  2. Clique em + ou Enviar skill.
    3. 
      
  3. Clique em Mostrar o .zip na skill abaixo: a pasta abre com o arquivo selecionado. Escolha esse arquivo no Claude.
    4. 
      
  4. Deixe a skill ligada e marque Já enviei aqui. Repita para as outras.
    5. 
    

    
O Claude Desktop roda na nuvem: use essas skills só com material que possa sair desta máquina. Para dados reais de investigação, use o Assistente de IA com IA local.

Fila de indexação vários casos, um depois do outro

    
Cada linha vira um caso separado. O IPED processa um por vez para não disputar memória; o painel inicia o próximo sozinho. No fim, os casos podem formar um grupo para abrir juntos no IPED e para a análise multicasos.

Conexões de IA (MCP)

  
O MCP deixa a IA consultar o caso e, com a escrita liberada, criar marcadores e comentários. Cada chamada fica no log de auditoria do caso.

  

    
MCP nesta máquina

    

    

      
    

    
Vale para as próximas conversas. Feche o IPED antes de a IA marcar itens, ou recarregue o caso depois, para não sobrescrever os marcadores.

    

    

  

  

    
Programas de IA

    
ProgramaSituaçãoArquivo

    
Depois de ligar, feche e abra o programa de IA. Antes de alterar, uma cópia do arquivo fica ao lado (.bak-pcba-…). Claude Desktop e Antigravity usam modelos na nuvem: o conteúdo que a IA lê do caso sai da máquina. Para dados reais, use IA local (Assistente de IA com Ollama ou LM Studio, ou Hermes com modelo local).

  

  

    
IA local nesta máquina

    
procurando…

    
As regras da PCBATech pedem IA local em produção. O painel acha o Ollama e o LM Studio mesmo com o servidor desligado e liga o servidor quando você envia uma pergunta no Assistente. Use um modelo com ferramentas (tool use), como qwen2.5, qwen3 ou llama3.1.

  







  
Multicasos

  
Cruza casos diferentes: telefones, contas e e-mails em comum, titular de um caso que aparece como contato em outro, e uma rede única com todos. Também abre os casos juntos no IPED.

  

    
Casos

    

      

    

    

      

    
A análise usa os números de cada caso (Visão do caso > Atualizar). Caso que ainda não tem os números aparece avisado.

  

  







  
4. Relatório técnico

  
Monte o RT no modelo da PCBA. O rascunho fica dentro do caso (pasta iped-pcba-relatorio) e a IA pode ajudar a preenchê-lo pelo MCP. O que estiver entre [colchetes] sai em vermelho no Word para você completar. A conclusão é sempre do analista.
